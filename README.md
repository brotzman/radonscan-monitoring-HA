# Radon Monitoring Home Assistant Repository 5.1.0

This repository contains the Home Assistant app **Radon Monitoring** for compatible GQ RadonScan devices.

Version 5.1.0 adds a responsive Home Assistant location summary and a threshold-based Radon traffic light to the Overview. The former Expert view has been removed from the interface and sidebar; operational details remain available under Devices & System and Settings. Location data is read only from Home Assistant's local Core configuration, without external geocoding.

See `gq_radonscan/README.md`, `gq_radonscan/DOCS.md` and `gq_radonscan/CHANGELOG.md` for installation, operation and release details.
